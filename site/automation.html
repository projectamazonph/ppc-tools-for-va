Bid Rules You Can Build

Rule 1: ACoS-Based Bidding

Adjust bids based on campaign ACoS relative to target:

IF ACoS > Target + 15% THEN Reduce bid 15% IF ACoS < Target - 10% THEN Increase bid 10% IF ACoS within ±10% of Target THEN Keep bid same

Rule 2: Volume-Based Scaling

Scale bids when campaign is performing well:

IF Orders >= 10 AND ACoS < Target THEN Increase budget 20% IF Spend >= 80% of budget AND ACoS < Target THEN Increase budget 10%

Rule 3: Placement Optimization

Adjust placement bids based on performance:

IF Top of Search ACoS < Target THEN Increase placement bid +25% IF Product Page ACoS > Target + 20% THEN Decrease placement bid -15%

DIY Automation with Google Sheets

Setting Up Automated Reporting

  1. Create a new Google Sheet
  2. Use Amazon Advertising API or manual CSV exports
  3. Create calculated columns for ACoS, ROAS, CVR
  4. Use conditional formatting to highlight issues
  5. Share with client for live updates

Common Automation Mistakes

  • Setting rules too aggressive: Don't change bids more than 20% at once
  • Not monitoring automation: Review automated changes weekly
  • Ignoring data: Let 2-3 weeks of data accumulate before automating
  • No guardrails: Always set min/max bid limits
  • Automating wrong tasks: Search term analysis should always be manual
